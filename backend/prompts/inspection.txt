Inspect the photograph as evidence. Assess jewellery presence and visibility first, then identify the physical jewellery and record only clearly visible findings.

TARGET
Look for the objects placed for inspection on the main surface, pan, tray, or inside the presented packet. Trace each object's edges, links, fastenings and overlap with the surface. Count only physical ornaments. A picture, logo, reflection or outline on paper or a mat is background. Printed handcuffs, even when jewellery rests over them, are background and never part of a count, type or feature. An item casting a shadow on a printed picture can still be real. Ignore worn watches, tools, labels, paperwork and unrelated objects. A weighing chamber is a scale, not a packet.

PRESENCE AND VISIBILITY
present = recognisable physical jewellery; absent = the inspection area is visible and contains no jewellery; unknown = hidden or unidentifiable contents. An empty packet or pan, loose beads, glass, coins, calibration weights and hardware alone are absent.
Rate cropping, obstruction, blur and glare by their effect on jewellery: none = detail is usable, local = some detail lost, substantial = most detail lost, unknown = insufficient evidence. Cropping means the item extends beyond the photo. Obstruction means something covers it. Softness or glare elsewhere in the image is irrelevant. Clear packaging and the hidden reverse side do not by themselves limit inspection.
Use separation=limits_inspection when tangled or overlapping pieces cannot be traced; adequate when separate pieces can be distinguished; not_applicable for a single item; unknown if uncertain. For absent jewellery use unknown visibility fields.

JEWELLERY FINDINGS
Identify each real ornament from construction. A broad decorated arc with tapered sides, end chains or a tie suggests a necklace or choker. Use bangle only for a rigid wrist band. A loop alone cannot distinguish neck from wrist wear. A coiled chain is not proof of a necklace, bracelet or single item. An attached pendant belongs to its necklace. Include separately visible earrings even when they lie over a printed image. Set c to the total only if every piece is traceable; count earrings individually. Omit c for a tangle or partly hidden set. Never use c=1 for a pile.
Report thread or cord only for a visible textile strand; a metal chain is not thread. Report black beads only for discrete black beads strung on an ornament. Report coloured stones or beads only when distinct and mounted or strung. Ignore shadows, dark metal, gold-coloured metal beads, tray colours and printed marks when looking for these features.
Describe colour, links, coils, decoration and any attached pendant when visible. No assumptions about metal, purity, authenticity, value or hidden contents.

SCALE
Set scale=present for a physical weighing device, even with its screen cropped out. Use absent if no scale; unknown if unsure. display_area is top, middle or bottom by where the scale screen is located in the photograph, not the pan, or unknown if unclear/out of frame. Do not transcribe digits in this step.

Return one JSON object matching the schema. Use note for up to 20 words about the physical jewellery. Name each clearly identifiable type and any verified detail. For an ambiguous object, describe its visible construction and omit the type. Do not add background objects to the note or assign a priority.
